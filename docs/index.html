Quick Start

Open a terminal in the project folder, then run:

npm install
npm run dev

After Vite starts, open the local URL shown in the terminal. The default is usually http://localhost:5173/.

Where To Edit

  • index.html contains the story markup.
  • src/scripts/main.js contains animation timing and interactions.
  • src/styles/main.css contains layout, visual styling, and responsive rules.
  • public/assets/ contains runtime media files.
  • docs/ contains this learning documentation.
Learning goal: do not memorize every line. First understand the pattern: scroll height creates time, the fixed camera shows the scene, and GSAP connects both together.
