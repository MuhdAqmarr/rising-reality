Run & Edit Guide

Start here when you want to run or change the project.

Follow this page from top to bottom. It covers setup, local preview, editing text, changing assets, adjusting animation, debugging, and preparing the final build.

1. Install The Tools

Install Node.js first. This project uses Vite, so it runs through npm commands.

Recommended: use the current LTS version of Node.js.

2. Open The Project Folder

Open a terminal inside the project folder:

C:\Dev\Web\gsap-project\rising-reality

If you are using VS Code, open the folder first, then use the built-in terminal.

3. Install Dependencies

Run this once after downloading or cloning the project:

npm install

This creates the node_modules folder. Do not edit that folder manually.

4. Run The Website Locally

Start the development server:

npm run dev

Open the local URL shown by Vite. It is usually:

http://localhost:5173/
Keep the terminal running while editing. Vite will auto-refresh the browser when files change.

5. Know Which File To Edit

Task File What To Look For
Change story text index.html Find the scene section, then edit headings and paragraphs.
Move or style elements src/styles/main.css Find the class name from HTML, then update its CSS rule.
Change animation timing src/scripts/main.js Find the scene comment, then adjust GSAP timeline values.
Add or replace images public/assets/ Place the file here, then reference it with /assets/file-name.png.
Read learning notes docs/ Open docs/index.html in the browser.

6. Edit Text Safely

Find the scene in index.html. For example, Scene 6 uses:

<section class="scene scene-6">

Edit text inside headings, paragraphs, and buttons. Keep class names unchanged unless you also update CSS and JavaScript.

7. Replace Or Add Assets

  1. Put the new image, video, SVG, or GIF in public/assets/.
  2. Use a simple filename, for example new-forest.webp.
  3. Reference it from HTML with /assets/new-forest.webp.
  4. Reference it from CSS with url('/assets/new-forest.webp').

After replacing an asset, refresh the browser and check that it appears in the correct scene.

8. Adjust Styling

Use src/styles/main.css for layout and appearance.

Good changes for beginners:

  • Change font size with font-size.
  • Change color with color or background.
  • Change spacing with gap, margin, or padding.
  • Move decorative elements with transform.

9. Adjust Animation

Use src/scripts/main.js for GSAP animation.

Common values to adjust:

  • duration controls how long an animation segment takes inside the timeline.
  • opacity or autoAlpha controls fade in and fade out.
  • x, y, scale, and rotation control movement.
  • Timeline labels such as scene6start help position animations.

After changing animation timing, scroll through the full page from start to end.

10. Debug Before Sharing

  • Run npm run build to catch missing imports or broken build paths.
  • Check the browser console for red errors.
  • Check that images load from /assets/....
  • Check Scene 5 Enter-key interaction and button clicks.
  • Check the final CTA button hover effect.

11. Build The Final Version

When editing is complete, run:

npm run build

Vite will create a production build in dist/.

12. Student Editing Rules

  • Do not edit node_modules.
  • Do not rename class names unless you update all matching HTML, CSS, and JS references.
  • Keep new assets inside public/assets/.
  • Make one change at a time, then refresh and test.
  • Use the Scene Guide when you are not sure where a section belongs.
